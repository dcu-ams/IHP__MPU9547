# MPU9547

Single-technology IP library consisting of a reduced functionality Z80 processor and divided down ring oscillator in a QFN32 package.

- dependencies    : none.
- doc             : user documentation.
- measurements    : will be populated once samples received.
- MPU9547-main    : analog, digital, package and toplevel design files.
- release/v.1.0.1 : gds for MPW with flat netlist and reports (drc, density and tape-in)
